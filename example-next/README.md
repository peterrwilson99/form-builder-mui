# Form Builder MUI - Next.js Example

This is a simple Next.js example for testing the `form-builder-mui` components.

## Getting Started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Run the development server:

   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) to test the form builder components.

## What's Included

This example demonstrates:

- Form Builder component
- Form Viewer component
- Various form input types (text fields, radio buttons, checkboxes, etc.)
- Form submission and saving functionality
- Material-UI integration

## Testing Components

The main page (`pages/index.tsx`) includes tabs to test different aspects of the form builder:

- **Viewer**: Test form display and interaction
- **Builder**: Test form creation and editing
- **JSON Input**: Test importing/exporting form configurations

This is primarily for development and testing purposes.
